# 📱 산업기사 자격증 마스터 (CBT & 기출변형 웹앱)

> **⚠️ PWA 개발 필수 가이드라인**  
> **캐시가 꼬일 수 있으니 꼭 기존 앱을 완전히 삭제하고 설치하셔야 합니다.**

한국산업인력공단(Q-Net) 출제 기준에 맞춘 산업기사 자격증 수험생을 위한 **모바일 & 데스크탑 통합 CBT 학습 웹앱**입니다.  
비용 0원(무료), 외부 유료 API 없이 순수 웹 표준(Vanilla JS / CSS3 / PWA)으로 개발되어 하위 호환성이 우수하고 가볍습니다.

## 🌐 모바일 접속 주소 (GitHub Pages)

GitHub Pages 설정 후 아래 주소로 스마트폰 및 PC에서 언제 어디서나 접속할 수 있습니다:
👉 **https://kiuza1004.github.io/engineer1/**

### 📲 모바일 홈 화면에 앱으로 설치하는 방법 (PWA)
1. **아이폰(iOS / Safari)**:
   - 사파리 브라우저에서 주소 접속 ➡️ 하단 중앙 **[공유 버튼]** 터치 ➡️ **[홈 화면에 추가]** 선택
2. **갤럭시/안드로이드(Android / Chrome)**:
   - 크롬 브라우저에서 주소 접속 ➡️ 우측 상단 **[점 3개 메뉴]** 터치 ➡️ **[앱 설치]** 또는 **[홈 화면에 추가]** 선택
3. 홈 화면에 생성된 아이콘을 터치하면 상단 주소창 없는 **전체화면 모바일 앱**으로 실행됩니다.
4. 오프라인 캐싱(Service Worker)을 지원하여 인터넷 연결이 불안정해도 문제 풀이가 가능합니다.

## 🚀 3대 주요 학습 메뉴

1. **📋 기본 정보 정리 메뉴**
   - **자격증 개요**: 응시 자격, 진로 및 전망, 수수료
   - **정기 시험 일정**: 연간 회차별 원서접수, CBT 시험일, 합격발표일 테이블
   - **응시 자격 자가진단**: 전공, 경력, 학점은행제 조건별 응시 자격 충족 여부 및 제출 서류 자동 판정
   - **시험 과목 및 합격 기준**: 과목당 40점 과락 방지 및 전 과목 평균 60점 이상 합격선 안내
   - **핵심 요약 노트**: 시험 전 필수 암기 족보 아코디언 제공

2. **📝 기출문제 풀이 메뉴 (CBT)**
   - **연습 모드**: 문제 풀이 즉시 정답 및 상세 해설 확인
   - **실전 모의고사 모드**: 실제 시험 제한시간 타이머 작동, OMR 마킹 시트, 문항 바로가기, 북마크(별표)
   - **성적표 및 리포트**: 100점 만점 환산, 합격/불합격 판정
   - **오답 집중 복습**: 틀린 문제만 모아서 해설과 함께 집중 재학습

3. **💡 기출변형 응용문제 메뉴 (신유형 대비)**
   - 기출문제의 핵심 개념을 기반으로 수치, 코드 트레이싱, 조건, 보기를 고난도로 비튼 실전 응용 모의고사
   - 각 문제마다 **[🎯 원본 기출 개념]**과 **[⚡ 변형 포인트]** 배지를 제공하여 함정 극복 능력 향상

## 💻 로컬 PC 실행 방법 (오프라인)

별도의 npm 패키지 설치 없이 Node.js만 있으면 바로 구동 가능합니다:
```bash
# 실행 방법 1: 배치 파일 더블 클릭
실행하기.bat

# 실행 방법 2: 터미널 명령
node server.js
```
브라우저에서 `http://localhost:3000` 접속
