# 🦺 산업안전산업기사 마스터 (CBT & 기출변형 웹앱)

> **⚠️ PWA 개발 필수 가이드라인**  
> **캐시가 꼬일 수 있으니 꼭 기존 앱을 완전히 삭제하고 설치하셔야 합니다.**

한국산업인력공단(Q-Net) 안전관리 분야 출제 기준에 맞춘 **산업안전산업기사 필기 합격 전용 모바일 & 데스크탑 통합 CBT 학습 웹앱**입니다.  
비용 0원(무료), 외부 유료 API 없이 순수 웹 표준(Vanilla JS / CSS3 / PWA)으로 개발되어 스마트폰과 PC 어디서나 빠르고 쾌적하게 동작합니다.

---

## 🌐 실시간 모바일 접속 주소 (GitHub Pages)

스마트폰 브라우저(Safari, Chrome) 또는 PC에서 즉시 접속할 수 있습니다:  
👉 **https://kiuza1004.github.io/engineer1/**

### 📲 모바일 홈 화면에 앱으로 설치하는 방법 (PWA)
1. **아이폰(iOS / Safari)**:
   - 사파리 브라우저에서 접속 ➡️ 하단 중앙 **[공유 버튼]** ➡️ **[홈 화면에 추가]**
2. **갤럭시/안드로이드(Android / Chrome)**:
   - 크롬 브라우저에서 접속 ➡️ 우측 상단 **[점 3개 메뉴(⋮)]** ➡️ **[앱 설치]** 또는 **[홈 화면에 추가]**
3. 홈 화면에 생성된 녹색 안전모 아이콘을 터치하면 상단 주소창이 없는 **전체화면 모바일 앱**으로 실행됩니다.
4. 오프라인 캐시(Service Worker)를 탑재하여 인터넷 연결이 끊겨도 문제 풀이가 가능합니다.

## 🚀 3대 주요 학습 메뉴

1. **📋 1. 기본 정보 메뉴**
   - **자격증 개요**: 안전관리자 법정 선임 기준, 진로 및 우대사항, 필기/실기 수수료
   - **정기 시험 일정**: 연간 회차별 원서접수, CBT 시험일, 합격발표일 테이블
   - **응시 자격 자가진단**: 전공(안전/공학계열), 실무경력, 학점은행제 요건별 합격 가능 여부 자동 판정
   - **5개 시험 과목 및 합격 기준**: 
     - 1과목: 산업안전관리론 (20문항)
     - 2과목: 인간공학 및 시스템안전공학 (20문항)
     - 3과목: 기계위험방지기술 (20문항)
     - 4과목: 전기 및 화학설비 위험방지기술 (20문항)
     - 5과목: 건설안전기술 (20문항)
     - 과락(40점 미만) 방지 및 전과목 평균 60점 이상 합격선 안내
   - **핵심 공식 & 암기 족보**: 하인리히·버드 재해비율, 도수율·강도율·FSI 공식, FTA 논리게이트, 롤러기 급정지거리 등 요약 아코디언

2. **📝 2. 기출문제 풀이 메뉴 (15문항 CBT)**
   - **연습 모드**: 1문제 풀 때마다 즉시 정답 및 상세 해설 확인
   - **실전 모의고사 모드**: 25분 제한시간 타이머 작동, OMR 마킹 시트, 문항 점프, 북마크(별표) 기능
   - **종합 성적표**: 100점 만점 환산, 합격/불합격 판정
   - **오답 집중 복습**: 틀린 문제만 모아서 해설과 함께 집중 재학습

3. **💡 3. 기출변형 응용문제 메뉴 (고난도 8선)**
   - 기출문제의 공식을 비틀거나 수치, 법령 수치, 병렬 신뢰도를 심화한 실전 변형 모의고사
   - 각 문제마다 **[🎯 원본 기출 개념]**과 **[⚡ 변형 포인트]** 배지를 제공하여 함정 극복 능력 향상
