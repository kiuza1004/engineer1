# 🦺 산업안전산업기사 마스터 (CBT & 스마트 오답노트 웹앱)

> **⚠️ PWA 개발 필수 가이드라인**  
> **캐시가 꼬일 수 있으니 꼭 기존 앱을 완전히 삭제하고 설치하셔야 합니다.**

한국산업인력공단(Q-Net) 안전관리 분야 출제 기준에 맞춘 **산업안전산업기사 필기 합격 전용 모바일 & 데스크탑 통합 CBT 학습 웹앱**입니다.  
비용 0원(무료), 외부 유료 API 없이 순수 웹 표준(Vanilla JS / CSS3 / PWA)으로 개발되어 스마트폰과 PC 어디서나 빠르고 쾌적하게 동작합니다.

## 🌐 실시간 모바일 접속 주소 (GitHub Pages)

스마트폰 브라우저(Safari, Chrome) 또는 PC에서 즉시 접속할 수 있습니다:  
👉 **https://kiuza1004.github.io/engineer1/**

### 📲 모바일 홈 화면에 앱으로 설치하는 방법 (PWA)
1. **아이폰(iOS / Safari)**:
   - 사파리 브라우저에서 접속 ➡️ 하단 중앙 **[공유 버튼]** ➡️ **[홈 화면에 추가]**
2. **갤럭시/안드로이드(Android / Chrome)**:
   - 크롬 브라우저에서 접속 ➡️ 우측 상단 **[점 3개 메뉴(⋮)]** ➡️ **[앱 설치]** 또는 **[홈 화면에 추가]**
3. 홈 화면에 생성된 녹색 안전모 아이콘을 터치하면 상단 주소창이 없는 **전체화면 모바일 앱**으로 실행됩니다.
4. 오프라인 캐시(Service Worker)를 탑재하여 인터넷 연결이 끊겨도 문제 풀이가 가능합니다.

## 🚀 4대 주요 학습 메뉴

1. **📋 1. 기본 정보 & 5개 과목 기출 핵심요약노트**
   - **과목별 기출 핵심요약 (1과목~5과목 칩스 네비게이션)**:
     - 1과목: 안전관리조직(라인/스태프), 하인리히·버드 재해비율, 도수율·강도율·FSI 계산공식, 보호구(안전모/방진마스크)
     - 2과목: 양립성 4종, 직렬/병렬 시스템 신뢰도, FTA(컷셋/패스셋), Fail-Safe vs Fool-Proof
     - 3과목: 기계 6대 위험점, 롤러기 급정지거리(1/3, 1/2.5) 및 조작부 위치, 프레스 5대 방호장치, 연삭기 규격
     - 4과목: 감전 위험한계 및 Dalziel 공식(I = 165/√T), 누전차단기 규격, 정전기 방지 4대책, 방폭구조(d, p, o, e, ia)
     - 5과목: 안전난간 설치규격, 비계 벽이음 간격(단관 5m/틀 6m, 8m), 가설통로 경사각 및 계단참, 굴착면 기울기
   - **자격 개요 / 시험 일정 / 응시 자격 자가진단 / 합격 기준**

2. **📝 2. 기출문제 풀이 메뉴 (15문항 CBT)**
   - 1과목 산업안전관리론부터 5과목 건설안전기술까지 전 과목 핵심 기출문항
   - **연습 모드**: 문제 풀이 즉시 정답 및 상세 해설 제공, 오답 시 스마트 오답노트에 실시간 자동 누적
   - **실전 모의고사 모드**: 25분 타이머, OMR 마킹 시트, 북마크, 종합 성적표 및 과락 체크

3. **💡 3. 기출변형 응용문제 메뉴 (고난도 8선)**
   - 잔업/특근 복합 FSI 종합재해지수 연산, 3중 병렬 고장확률, 롤러기 원주속도 급정지거리, 달지엘 심실세동전류 계산 등
   - 문항별 **[🎯 원본 기출 개념]**과 **[⚡ 변형 포인트]** 배지 분석 제공

4. **🚨 4. 스마트 오답노트 메뉴 (신규 탑재!)**
   - 기출문제와 응용문제를 풀며 틀린 문제들이 로컬스토리지에 **실시간 자동 저장**
   - 과목별 오답 통계 요약 칩 (과목별 취약점 한눈에 파악)
   - 내가 선택한 답 vs 정답 및 상세 해설 비교 복습
   - **"🔥 오답만 다시 풀기"** 재도전 모의고사 기능 (맞추면 오답노트에서 자동 마스터 삭제!)
   - 개별 문제 마스터(삭제) 및 전체 비우기 지원
